# W2-PM2 — Footprinting & Reconnaissance with GHDB

## Objective

Practice search-engine-based footprinting using Google/GHDB-style search operators and document publicly available, non-sensitive mathematics PDF resources.

> **Safety note:** This report documents public educational PDFs only. It does not include exposed cameras, private systems, credentials, or other sensitive resources.

## Search Queries Used

1. `filetype:pdf mathematics`
2. `site:edu filetype:pdf mathematics`
3. `site:edu filetype:pdf mathematics "lecture notes"`
4. `site:edu filetype:pdf mathematics "lecture notes" calculus`
5. `site:edu filetype:pdf mathematics "linear algebra" lecture notes`
6. `site:edu filetype:pdf mathematics "probability" "lecture notes"`
7. `site:edu filetype:pdf mathematics "differential equations" "lecture notes"`
8. `site:edu filetype:pdf mathematics "number theory" "lecture notes"`
9. `site:edu filetype:pdf mathematics "abstract algebra" "lecture notes"`

## Key Learning

- `filetype:pdf` restricts results to PDF documents.
- `site:edu` narrows results toward educational domains.
- Quoted phrases such as `"linear algebra"` or `"lecture notes"` make searches more specific.
- Search operators can be combined to improve reconnaissance and information discovery.
- Reconnaissance should remain within authorized and non-sensitive targets.
