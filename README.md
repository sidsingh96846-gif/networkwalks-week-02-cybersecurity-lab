# 🔐 Networkwalks Week 02 — Cybersecurity Lab

## Footprinting, Reconnaissance & Network Scanning

This repository contains my Week 02 practical work for the
Networkwalks Cybersecurity & Ethical Hacking training.

## 🎯 Objectives

- Understand cybersecurity footprinting and reconnaissance
- Perform WHOIS enumeration
- Identify web technologies using WhatWeb
- Perform DNS enumeration
- Analyze HTTP response headers
- Detect Web Application Firewalls
- Perform DNS reconnaissance
- Practice OSINT techniques
- Perform authorized network scanning

## 🛠️ Tools

- Kali Linux
- WHOIS
- WhatWeb
- NSLookup
- cURL
- WAFW00F
- DNSRecon
- Maltego
- theHarvester
- Zenmap / Nmap
